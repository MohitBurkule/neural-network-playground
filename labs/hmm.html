Hidden Markov Model Lab

Forward-Backward · Viterbi · Baum-Welch EM — interactive visualization

Select a scenario and generate or enter an observation sequence.

How to Use

  • Scenario: pick a hidden-state model (weather, casino, health).
  • Generate: sample a random observation sequence from the current HMM.
  • Viterbi: find and highlight the most-likely hidden state path (gold nodes).
  • Forward: run Forward algorithm; nodes show α probabilities (green intensity).
  • Baum-Welch: animate EM training — watch A, B, π and the log-likelihood chart converge.
  • Reset: restore original parameters (undo Baum-Welch).
