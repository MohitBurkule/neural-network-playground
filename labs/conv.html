How it works: For each output pixel at position (x, y), take the k×k neighborhood in the input, multiply each input value by the corresponding kernel weight, sum all products, divide by the divisor, add the offset, then clamp to [0, 255]. The yellow box on the input shows the current neighborhood; the red dot on the output shows the computed pixel. The color-coded grid below the controls shows each product — green = positive, red = negative.
